Small Business Sales Analysis

Project Overview

This is my first Excel data analysis project. I analysed 1,000 sales records to identify business performance, profitability and shipping trends.

Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas

Data Cleaning

- Checked for duplicate records.
- Checked for missing values.
- Verified date formats.
- Checked shipping and order date consistency.
- Calculated shipping duration.

Key Performance Indicators

Metric| Result
Total Sales| 955,613.76
Total Cost| 740,666.79
Total Profit| 214,946.97
Profit Margin| 22.49%
Average Shipping Time| 3.805 days

Key Insights

- Technology generated the highest profit.
- Technology contributed approximately 66.4% of total profit.
- Furniture generated 50,497.27 in profit.
- Office Supplies generated 21,690.33 in profit.
